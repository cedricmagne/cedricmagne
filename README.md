## What I'm building

### [Rness](https://rness.dev) --- AI engineering harness

An open-source TypeScript CLI for managing engineering context across
repositories and AI coding agents.

Rness helps teams keep **rules, plans, specifications, ADRs, and project
memory** consistent as work moves across repositories and agent
sessions. The goal is to make AI-assisted development more structured,
auditable, and aligned with a project's engineering standards.

`TypeScript` · `Node.js` · `GitHub APIs` · `AI coding workflows`

### [Lendwise](https://lendwise.fi) --- DeFi lending data

Building data infrastructure and backend services for DeFi lending
research, aggregating lending-market information across protocols such
as Morpho, Aave, and Compound.

The platform's data model and pipelines cover **900+ lending markets**,
with a GraphQL API and open-source tooling to make protocol data easier
to work with.

`TypeScript` · `Node.js` · `GraphQL` · `DeFi` · `On-chain data`

### Consensys / Infura --- Production Web3 products

Worked on the Infura dashboard and developer experience at Consensys,
contributing to a production application used by Web3 developers.

Highlights included improvements associated with **+20% onboarding** and
**−7% churn**, alongside CI/CD workflows supporting **20+ deployments
per day**.

`TypeScript` · `React` · `Next.js` · `APIs` · `GitHub Actions` · `CI/CD`
